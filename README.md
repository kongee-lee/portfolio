# portfolio

## 부산 명소 지도

부산 지도 위에 명소를 핀으로 보여 주는 웹앱이에요.
- 핀을 누르면 장소 이름과 위도·경도가 나와요.
- 지도를 눌러 **나만의 명소**를 등록하고, 고치고, 지울 수 있어요.
- 등록한 명소는 브라우저에 저장돼서 창을 닫았다 열어도 남아 있어요.

### 인터넷 주소로 보기 (가장 쉬움)
GitHub Pages가 켜져 있다면 내 주소를 열기만 하면 돼요.
컴퓨터와 휴대전화 모두 열 수 있어요.

### 내 컴퓨터에서 켜 보기
1. **Node.js 설치하기**: https://nodejs.org 에서 "LTS"라고 적힌 버튼을 눌러 받고, 설치해요.
2. **코드 받기**: GitHub의 이 저장소 화면에서 초록색 `Code` 버튼 → `Download ZIP`을 눌러 받고, 압축을 풀어요.
3. **터미널 열기**: 압축을 푼 폴더에서 "터미널"(검은 글자 창)을 열어요.
   - 윈도우: 폴더를 연 뒤 위쪽 주소 칸을 누르고 `cmd`를 쓰고 Enter
   - 맥: 폴더를 오른쪽 클릭 → `폴더에서 새로운 터미널`
4. **준비하기**: 아래 글자를 그대로 치고 Enter 키를 눌러요. 처음 한 번만 하면 돼요.
   ```
   npm install
   ```
5. **켜기**: 아래 글자를 치고 Enter 키를 눌러요.
   ```
   npm start
   ```
6. **보기**: 인터넷 창(크롬 등)을 열고 주소 칸에 `http://localhost:3000` 을 쳐요.
7. **끄기**: 터미널에서 `Ctrl` 키와 `C` 키를 함께 눌러요.

### 나만의 명소 등록하기
1. 오른쪽(휴대전화는 지도 아래) **장소 이름** 칸에 이름을 써요.
2. 지도에서 원하는 곳을 눌러요. 주황색 동그라미가 생기고 위도·경도가 나와요.
3. 이름과 위치를 확인하고 **저장**을 눌러요.
4. **나만의 명소** 목록에서 **수정**을 누르면 이름이나 위치를 고칠 수 있고, **삭제**를 누르면 지울 수 있어요.

이름이 비었거나, 위치를 안 골랐거나, 이미 있는 이름·위치이면 저장되지 않고 빨간 글씨로 알려 줘요.

### 자동 시험 돌리기
터미널에서 아래 글자를 치면 저장·수정·삭제가 잘 되는지 컴퓨터가 스스로 확인해요.
```
npm test
```
마지막에 `fail 0`이 보이면 모두 통과한 거예요.

### 예시 명소를 더 넣고 싶을 때
`places.js` 파일을 열고, 있는 줄을 따라 한 줄을 더 써요.
```
{ id: "taejongdae", name: "태종대", lat: 35.0533, lng: 129.0876 },
```
- `id`: 장소마다 다른 영어 이름
- `name`: 화면에 보일 이름
- `lat`: 위도, `lng`: 경도

### 파일 설명
| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면의 뼈대 |
| `style.css` | 색깔·크기 같은 모양 |
| `places.js` | 예시 명소 목록 |
| `storage.js` | 나만의 명소 저장·수정·삭제, 빠진 입력과 중복 막기 |
| `app.js` | 지도, 핀, 등록 칸, 목록을 움직이는 코드 |
| `test/storage.test.js` | 자동 시험 |
| `vendor/leaflet/` | 지도 도구(Leaflet) 파일 |
| `server.js` | 내 컴퓨터에서 켜 볼 때 쓰는 작은 서버 |
| `package.json` | 필요한 패키지와 명령 목록 |
