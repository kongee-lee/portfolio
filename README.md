# portfolio

## 부산 명소 지도

부산 지도 위에 명소를 핀으로 보여 주는 웹앱이에요.
핀을 누르면 장소 이름과 위도·경도가 나와요.

### 인터넷 주소로 보기 (가장 쉬움)
GitHub Pages가 켜져 있다면 내 주소를 열기만 하면 돼요.
컴퓨터와 휴대전화 모두 열 수 있어요.

### 내 컴퓨터에서 켜 보기
1. **Node.js 설치하기**: https://nodejs.org 에서 "LTS"라고 적힌 버튼을 눌러 받고, 설치해요.
2. **이 폴더 열기**: 이 프로젝트 폴더에서 "터미널"(검은 글자 창)을 열어요.
3. **준비하기**: 아래 글자를 그대로 치고 Enter 키를 눌러요. 처음 한 번만 하면 돼요.
   ```
   npm install
   ```
4. **켜기**: 아래 글자를 치고 Enter 키를 눌러요.
   ```
   npm start
   ```
5. **보기**: 인터넷 창(크롬 등)을 열고 주소 칸에 `http://localhost:3000` 을 쳐요.
6. **끄기**: 터미널에서 `Ctrl` 키와 `C` 키를 함께 눌러요.

### 장소를 더 넣고 싶을 때
`places.js` 파일을 열고, 있는 줄을 따라 한 줄을 더 써요.
```
{ id: "taejongdae", name: "태종대", lat: 35.0533, lng: 129.0876 },
```
- `id`: 장소마다 다른 영어 이름
- `name`: 화면에 보일 이름
- `lat`: 위도, `lng`: 경도

### 파일 설명
| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면의 뼈대 |
| `style.css` | 색깔·크기 같은 모양 |
| `places.js` | 명소 목록 |
| `app.js` | 지도를 그리고 핀을 꽂는 코드 |
| `vendor/leaflet/` | 지도 도구(Leaflet) 파일 |
| `server.js` | 내 컴퓨터에서 켜 볼 때 쓰는 작은 서버 |
| `package.json` | 필요한 패키지와 명령 목록 |
